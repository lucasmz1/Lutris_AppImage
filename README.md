# Lutris AppImage
<h4>This is an unofficial AppImage package for Lutris<h4/>
<br>I have fixed gamescope, but due to Lutris limitation you cannot use mangohud at same time as gamescope and the resolution of gamescope of the game must be game internal minimum 1280x720 if you are on a screen of 1920x1080, if you set another low resolution inside of the game you will have black borders on the screen. if you need hud for fps you can use dxvk_hud env var or galliun_hud for opengl games. this is not my faught maybe upstream issue.<br/>
<br>If you need a wine I recommend Krone4k's wine builds must precisely the wow64 builds https://github.com/Kron4ek/Wine-Builds <br/>
<br>Basically I don't install anything on my system to run a game I just download one of Krone4k's wine builds and add them to the system PATH using environment variable PATH<br/>
<br>Then I use I setup the wine bin in the option of wine's personanlized executable and then make it's playable<br/>
<br>If you face any issue report a bug<br/>
