# Lutris AppImage
<h4>This is an unofficial AppImage package for Lutris<h4/>
<br>Fixed wintricks not working<br/>
<br>Fixed controller not being recognized<br/>
<br>Added gamescope<br/>
<br>If you need a wine I recommend Krone4k's wine builds must precisely the wow64 builds https://github.com/Kron4ek/Wine-Builds <br/>
<br>Basically I don't install anything on my system to run a game I just download one of Krone4k's wine builds and add them to the system PATH using environment variable PATH<br/>
<br>Then I use I setup the wine bin in the option of wine's personanlized executable and then make it's playable<br/>
